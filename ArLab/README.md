# ArLab

Landing page TRIMUI Brick Pro dựng bằng React, Vite, TypeScript, Tailwind CSS và shadcn/ui. Hero dựa trên [thiết kế Figma](https://www.figma.com/design/Zer9wswylucrohZ5l9RkAV/Untitled?node-id=1-2).

```powershell
npm ci
npm run dev
```

Preview tại [localhost:5177](http://localhost:5177/). Chạy `npm run build` để xuất bản tĩnh vào `dist`.

`src/App.tsx` ghép các section và giữ trạng thái giỏ hàng. Các màu máy, gói dung lượng và giá nằm trong `src/lib/brick-pro.ts`. Checkout và newsletter là tương tác mô phỏng cho portfolio.
